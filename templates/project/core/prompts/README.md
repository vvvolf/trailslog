# Команды проекта

Здесь живут команды проекта для человека и агента: короткие Markdown-файлы
с входом, шагами и выходом. Это не копия приватных команд TrailsLog; проект
описывает свои команды сам.

Для машинно-читаемых действий используйте карточки возможностей в
`docs/meta/capabilities/`. Команда в `prompts/` может ссылаться на карточку,
но не дублировать её контракт.
