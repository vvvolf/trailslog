# Публичный журнал

Хронологическая запись: что сделано, ключевые вопросы, решения и ссылки на
полученное знание. Журнал не является базой знаний; значимое продвигается
в `docs/meta/knowledge/` или в живые документы.

Приватные наблюдения, имена, пути и evidence сюда не попадают. Они живут
в private track: `docs/tracks/private/log/`.
