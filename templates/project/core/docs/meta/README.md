# Meta

- `knowledge/` — понимание, решения, следы KA;
- `artefacts/` — производные документы: runbook, глоссарии, working set;
- `capabilities/` — карточки возможностей, если слой включён;
- `work_items/` — локальные черновики, вне git;
- `work_item_trails/` — закоммиченные полные следы Work Item.
