# Знания

Живые знания и следы Knowledge acquisition (KA).

Правила:

- KA — read-only след происхождения; старый KA не редактируется;
- новое понимание → новый KA с переходом «было → стало»;
- актуальное знание живёт в живых документах без пометки KA;
- утверждения о состоянии — со ссылкой на источник или пометкой
  `[не проверено]`;
- в конце оценки — раздел «что я не проверял».

Первая полезная запись: зачем существует проект, какую проблему решает и
что явно не входит в его границы.
