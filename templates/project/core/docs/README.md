# Документация

- `meta/knowledge/` — живые знания и следы KA;
- `meta/artefacts/` — производные документы, runbook, глоссарии;
- `meta/capabilities/` — карточки возможностей, если слой включён;
- `meta/work_items/` — черновики Work Item, вне git;
- `meta/work_item_trails/` — следы Work Item в git;
- `log/` — публичный журнал проекта;
- `tracks/ideas/` — идеи и задачи;
- `tracks/private/` — private track: `log/` и приватный конвейер,
  вне git или в приватном репозитории.

Модель слоёв следует TrailsLog: знание — живое; KA — read-only след
происхождения; производные документы не являются вторым источником истины.
