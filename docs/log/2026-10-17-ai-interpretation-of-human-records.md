# Записи человека + ИИ

Проект сильно разогнался, когда я вдохновился одной вещью: всё, что человек
написал для себя — мысли, пожелания, правила, заметки, — современный ИИ
может осмысленно использовать. Двумя способами.

Первый: ИИ может интерпретировать записи в том контексте, который человек
сам задаст. Это оправдывает главную ставку проекта. Сырые, неоформленные
записи можно позволить себе писать дёшево, потому что интерпретация больше
не обязана происходить в момент записи: её сделает потом ИИ. Написанное
один раз перестаёт быть мёртвой строчкой в архиве: с ним можно разговаривать,
его можно связать с другими записями, из него можно собрать картину
ситуации — а может, и целых процессов из жизни.

Второй: ИИ может выполнять написанные человеком инструкции как код. Это
позволяет организовать многие вещи в качестве, ранее недостижимом без
программирования.
