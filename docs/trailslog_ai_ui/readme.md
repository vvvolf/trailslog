# TrailsLog AI UI

> Эксперимент по разработке специализированных ИИ-интерфейсов как производных артефактов системы знаний.

## Идея

Обычно приложение состоит из исходного кода, который компилируется или интерпретируется в исполняемую программу.

В данном проекте исследуется другой подход.

Вместо генерации исполняемого файла из исходного кода формируется специализированный ИИ-интерфейс, предназначенный для выполнения определённой задачи внутри LLM.

Получившийся результат представляет собой не программу в традиционном смысле, а инструкцию (system prompt), которая изменяет поведение языковой модели и превращает её в специализированного помощника.

Проект рассматривает LLM как среду исполнения, а промпт — как исполняемый интерфейс.

## Происхождение проекта

Проект вырос из исследований, проводимых в рамках **TrailsLog**.

В процессе развития системы знаний стало понятно, что многие задачи удобнее выполнять не вручную, а с помощью специализированных ИИ-агентов.

Первым таким агентом стал агент генерации Work Item.

Со временем оказалось, что процесс создания подобных агентов можно формализовать и сделать воспроизводимым.

Так появился данный проект.

## Что находится в репозитории

Проект содержит ресурсы, необходимые для получения специализированного ИИ-интерфейса.

В текущей версии используются следующие файлы.

### `meta/`

База знаний, описывающая исследуемую предметную область.

Именно она является основным источником знаний, из которых формируется будущий ИИ-интерфейс.

### `trailslog-working-set-v0-hand-made.md`

Первая вручную собранная версия Working Set.

Представляет собой компактное представление содержимого Meta, достаточное для генерации специализированного ИИ-интерфейса.

В дальнейшем предполагается автоматическая сборка Working Set из Meta.

### `prompt-build-ai-ui.md`

Инструкция по построению нового Working Set.

Этот промпт запускает процесс последовательного анализа ресурсов и формирования производной модели.

Сам по себе он не содержит знаний предметной области.

### `prompt-generate-ai-ui.md`

Инструкция, которая использует подготовленный Working Set для генерации итогового системного промпта.

Именно этот шаг превращает производную модель знаний в готовый ИИ-интерфейс.

### `prompt-ai-ui.md`

Готовый исполняемый системный промпт.

Этот файл является результатом предыдущих этапов.

Именно он загружается в LLM и превращает обычную языковую модель в специализированного агента.

## Общая схема

В упрощённом виде процесс выглядит следующим образом.

```text
Meta
        │
        ▼
Working Set
        │
        ▼
prompt-build-ai-ui.md
        │
        ▼
prompt-generate-ai-ui.md
        │
        ▼
prompt-ai-ui.md
        │
        ▼
LLM
```

Таким образом система знаний постепенно преобразуется в специализированный ИИ-интерфейс.

## Что исследуется

Основной интерес проекта заключается не в создании отдельных промптов.

Исследуется возможность разработки ИИ-приложений как производных артефактов системы знаний.

В этой модели:

- знания становятся исходным материалом;
- Working Set выступает в роли производной модели;
- системный промпт становится исполняемым представлением этой модели;
- LLM выполняет роль среды исполнения.

Иными словами, исследуется возможность разработки приложений, в которых основным артефактом является не программный код, а модель знаний.

## Статус

Проект является исследовательским.

Архитектура продолжает развиваться по мере проведения экспериментов в основном проекте TrailsLog.

Некоторые элементы процесса пока выполняются вручную и рассматриваются как промежуточные решения.

В частности, текущая версия Working Set собрана вручную и в дальнейшем должна замениться автоматической сборкой.

## Связь с TrailsLog

Данный репозиторий не является самостоятельной системой знаний.

Он использует результаты исследований, выполняемых в проекте TrailsLog, и исследует способы превращения этих знаний в специализированные ИИ-интерфейсы.

В дальнейшем предполагается, что подобным образом смогут собираться различные специализированные агенты для разных задач на основе одной общей системы знаний.
