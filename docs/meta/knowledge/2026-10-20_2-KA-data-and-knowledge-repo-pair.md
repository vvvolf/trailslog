# Пара «данные — knowledge-репозиторий»

## Исходная ситуация

Работа над проектом порождает материалы: сырьё, выгрузки, нарезки,
производные данные. Первичны они — а не документация вокруг. Когда
возникает потребность в знании о проекте (решения, уроки, черновики,
история), в пару к данным — или к существующему репозиторию проекта —
создаётся knowledge-репозиторий модели понимания. Объёмные и/или
воспроизводимые данные остаются вне git; оставлять их безымянной кучей
рядом с репозиторием — кандидат на потерю: не описаны происхождение,
структура и способ восстановления.

## Приобретённое понимание

Данные и knowledge-репозиторий образуют пару; данные первичны,
репозиторий создаётся к ним. Правила:

1. **Разделение по природе материала**: в git — «мыслительное»
   (промпты, решения, отчёты, черновики); вне git — воспроизводимое и
   сырое (нарезки, выгрузки, производные данные), особенно если
   пересоздание дорого.
2. **Папка данных сама описывает себя**: в ней README с происхождением
   (откуда взялись данные), ожидаемой структурой, способом
   пересоздания (с оценкой стоимости — механически или прогоном
   модели) и инструкцией бекапа. Без такого README папка — кандидат
   на потерю и битую ссылку.
3. **Относительные ссылки**: из репозитория — `../<данные>/`; в README
   репозитория — раздел «Внешние данные» (путь, что там, как
   бекапить). Папка и репозиторий — одна архивная единица.
4. **Проверяемость восстановления**: после бекапа/восстановления —
   контроль по счётчикам (число файлов, имена) прямо из README папки.

## Изменение модели

Паттерн продолжает линейку переносимости конвейера
(`2026-10-19_5-conveyor-portability-layers.md`): слой формата/хранения
получает правило размещения данных вне репозитория. Появился при
первом применении сценария создания knowledge-репозитория стороннего
проекта — выносе материалов обследования в отдельный репозиторий
(2026-10-20).

## Замечания генерации

Паттерн записан по следу реального переноса; до проверки на других
случаях (например, репозиторий с готовым кодом проекта) остаётся
гипотезой. Открытое: граница «дорого пересоздавать» — порог объёма и
стоимости, после которого данные точно выносить.
