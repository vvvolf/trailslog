# Связанные коммиты

## Исходная ситуация

Единица понимания может рождаться событием, которое не помещается в один
репозиторий: знание фиксируется в одном, инструкции механизма — в другом.
История такого события разрывалась между репозиториями: ни по одной
истории в отдельности событие не восстанавливается.

## Приобретённое понимание

Связанные коммиты — продолжение принципа «Git — механизм сопровождения
истории знаний» (`2026-07-16_5-git-as-knowledge-history.md`). Там: коммит
фиксирует появление одной законченной единицы понимания. Здесь: когда
единица охватывает несколько связанных репозиториев, её появление
фиксируется связанными коммитами — по одному в каждом затронутом
репозитории, с одинаковым сообщением.

Тогда:

1. Событие — единица понимания — восстанавливается целиком: сообщение —
   общий ключ, по одному коммиту находятся остальные.
2. Сверка дешёва: расхождение сообщений сразу заметно.

## Изменение модели

Принцип истории знаний распространён на случай нескольких репозиториев:
единица понимания может фиксироваться связанными коммитами.
