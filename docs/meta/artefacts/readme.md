# Working Set

Данный каталог содержит артефакты, используемые для сопровождения документации Meta. Основное назначение каталога — сопровождение документа `Working Set`; отдельные артефакты относятся к другим механизмам Meta.

`Working Set` является производным документом Meta.

Его назначение — предоставить минимальный, но достаточный контекст, позволяющий новому участнику (человеку или ИИ) быстро продолжить работу над проектом без чтения всей документации Meta.

## Состав

### working_set.md

Актуальная версия Working Set.

Именно этот документ используется как рабочая память проекта.

### working_set_last_linter_answer.md

Последний результат работы линтера.

Документ предназначен для ручного применения изменений к `working_set.md`.

После внесения изменений может быть заменён новым результатом линтера.

### prompt_working_set_generator_gpt.md

Промпт генератора Working Set.

Используется для построения Working Set на основе документов Meta.

### prompt_working_set_linter_gpt.md

Промпт линтера Working Set.

Используется для сопровождения существующей версии Working Set.

Линтер анализирует изменения документации Meta и формирует минимальный Markdown-патч, необходимый для актуализации `working_set.md`.

### prompt_knowledge_acquisition_generator_gpt.md

Промпт генератора документов `Knowledge acquisition` из обсуждений.

Не относится к сопровождению Working Set. Использовался для формирования текущего корпуса документов KA в `docs/meta/`. Полное описание будет дописано при возвращении к теме генераторов.

## Общий принцип

Рабочим документом является только `working_set.md`.

Остальные файлы представляют собой инфраструктуру сопровождения Working Set и документации Meta.
