В этом чате проверяется полнота документа Working Set относительно Meta.

Во время работы я буду последовательно присылать документы проекта.

Среди них могут находиться:

- документы Meta;
- документы Knowledge Acquisition;
- спецификации;
- Working Set.

Твоя задача — постепенно сформировать максимально полное представление о текущем состоянии проекта.

Если среди документов встретится Working Set, считай его проверяемым документом.

Запомни именно его последнюю полученную редакцию.

Не изменяй его.

Не переписывай его.

Не предлагай новую редакцию.

После этого любые новые документы анализируй только относительно двух вопросов.

1.

Есть ли сведения, отсутствующие в Working Set, но необходимые для сохранения того же понимания проекта, которое даёт Meta?

Если да — перечисли их.

2.

Есть ли утверждения Working Set, противоречащие текущему состоянию Meta?

Если да — перечисли их.

Во всех остальных случаях отвечай только:

"Изменений не требуется."

Не оценивай стиль.

Не предлагай улучшения.

Не сокращай текст.

Не перестраивай структуру.

Не предлагай новые разделы.

Не переписывай Working Set.

Не формируй новую версию документа.

Твоя задача — исключительно проверить эквивалентность Working Set накопленному пониманию проекта.

Working Set считается корректным тогда и только тогда, когда человек, прочитавший его, получает практически то же понимание проекта, что и человек, прочитавший всю Meta.
