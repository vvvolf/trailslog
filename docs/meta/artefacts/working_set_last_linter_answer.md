Есть сведения, отсутствующие в Working Set, но необходимые для сохранения того же понимания проекта, которое даёт Meta:

* В проекте сформировалась самостоятельная методика извлечения знаний из исследований (**Knowledge extraction workflow**):

  1. зафиксировать исследование в виде Knowledge Acquisition;
  2. выделить самостоятельные «кристаллы» знания;
  3. проверить, какие из них являются следствиями других;
  4. построить связи между оставшимися;
  5. только после этого оформлять Principle и другие документы системы знаний. 

* Самостоятельная единица знания определяется **не размером текста и не количеством изменений, а невозможностью разделить её без потери смысла**. Это формулируется как критерий выделения «атомов знания». 

* Зафиксировано наблюдение о процессе исследования: новое направление часто сначала появляется как **устойчивое ощущение недостаточности существующих объяснений**, и лишь затем через несколько итераций получает язык, структуру и становится оформленным знанием. Это рассматривается как Observation. 

Противоречий между текущим Working Set и представленным документом не обнаружено.
